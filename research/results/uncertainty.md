# ความไม่แน่นอนของการทำนาย: บอกได้ไหมว่าคู่ไหนจะผิดมาก

ข้อมูลตัดแถว * ออก · error ใหญ่ = ΔE00 > 3 · Spearman ρ และ AUROC ยิ่งสูงยิ่งดี (AUROC 0.5 = เดาสุ่ม, 1.0 = แยกได้สมบูรณ์)

## random 5-fold

| ตัวชี้วัด | S-N + XGBoost ensemble×10 | S-N + GP |
|---|---|---|
| mean ΔE00 | 1.30 | 1.74 |
| Spearman ρ (ความไม่แน่นอน, error) | 0.30 | -0.03 |
| AUROC จับ error > 3 | 0.64 | 0.41 |
| ΔE00 ครึ่งที่มั่นใจ | 1.08 | 1.95 |
| ΔE00 ครึ่งที่ไม่มั่นใจ | 1.52 | 1.53 |
| เตือน 30% แรก จับ error ใหญ่ได้ | 47% | 24% |
